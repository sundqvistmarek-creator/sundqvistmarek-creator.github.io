Vim Basics!

What is vim?

Vim is used to write:

  • HTML
  • CSS
  • JavaScript

To open vim you write: vim "html file name"

Here are some tips and tricks

  • To escape vim press esc and then press colon q
  • To highlight a line press esc and then write 
    shift v
    • Highlight can also be used to copy paste in the terminal
    • To do this, after you highlight a line, you write: j for every line after that you want to highlight
    • Then press y to copy the highlighted text
    • To paste text, press: p on the line you want to paste your text in
  • Write: syntax on to give your code colors

Important!

This is the code for a minimal html file in vim:

<!DOCTYPE html>
            <html lang="en">
                <head>
                    <title>Hello World!</title>
                </head>
                <body>
                    <p>This is my first web page.</p>
                </body>
            </html>
